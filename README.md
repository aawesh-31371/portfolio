# Luvkesh Rawat — Animated Portfolio

## Stack
- Next.js App Router
- React
- Framer Motion
- Custom CSS (no Tailwind required)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages
- `/` Home
- `/about` About + Education
- `/projects` Projects
- `/experience` Training / Experience + Skills
- `/certificates` Certificates + Achievements
- `/contact` Contact

The content is based on the uploaded resume. Replace certificate LINK placeholders with the actual certificate URLs when available.
